# 07 — Signaux et diagnostics

## Signal : confusion, dispersion

Indices :
- "Je pars dans tous les sens."
- "J'ai trop d'idées."
- "Je ne sais pas ce que je veux."

Intervention :
- recentrage ;
- liste des curiosités ;
- choix d'un seul fil ;
- action simple.

## Signal : peur de ne pas y arriver

Indices :
- "C'est trop gros."
- "Je ne suis pas prêt."
- "Je ne sais pas par où commencer."

Intervention :
- découper l'éléphant ;
- chercher la version simple ;
- action de 20 minutes ;
- test sans enjeu.

## Signal : perfectionnisme

Indices :
- "Ce n'est pas encore assez bien."
- "Je lancerai quand ce sera parfait."
- "Je dois tout préparer."

Intervention :
- question "si c'était simple ?" ;
- offre brouillon ;
- feedback rapide ;
- améliorer au fil de l'eau.

## Signal : envie ou jalousie

Indices :
- "Cette personne m'énerve."
- "Elle fait tout ce que j'aimerais faire."
- "Je me compare."

Intervention :
- jalousie comme boussole ;
- identifier le désir caché ;
- emprunter une pratique ;
- agir à sa manière.

## Signal : manque de légitimité

Indices :
- "Qui suis-je pour faire ça ?"
- "Je ne peux pas dire que je suis..."
- "Je ne suis pas encore légitime."

Intervention :
- se prendre au sérieux ;
- nommer l'appel ;
- repérer les preuves de travail réel ;
- chercher un premier public.

## Signal : passion non viable

Indices :
- "J'adore ça mais je n'en vis pas."
- "Je donne tout gratuitement."
- "Je ne sais pas quoi vendre."

Intervention :
- argent ;
- donner/vendre ;
- offre simple ;
- revenu de transition ;
- test de paiement.

## Signal : travail rémunéré mais vide

Indices :
- "Je gagne ma vie mais je m'ennuie."
- "Je ne vois pas le sens."
- "Je me sens éteint."

Intervention :
- énergie + / énergie - ;
- zone de brillance ;
- ajustements internes ;
- activité parallèle ;
- exploration prudente.

## Signal : découragement après action

Indices :
- "J'ai essayé, ça n'a pas marché."
- "Je ne suis pas fait pour ça."
- "Personne n'a répondu."

Intervention :
- bilan après test ;
- célébrer l'action ;
- distinguer échec et information ;
- ajuster l'hypothèse ;
- refaire un test plus simple.
