# 03 — Exercices pratiques

## 1. Le rendez-vous avec soi

Durée : 5 à 20 minutes.

Consigne :
Prends un carnet. Éloigne ton téléphone. Assieds-toi, marche ou écris. Ne cherche pas à produire une réponse parfaite. Note ce qui revient.

Questions :

- Qu'est-ce qui cherche à attirer mon attention ?
- Qu'est-ce que j'évite ?
- De quoi ai-je besoin maintenant ?
- Qu'est-ce qui me rendrait plus vivant cette semaine ?

## 2. La liste des curiosités

Consigne :
Liste cinq domaines qui attisent ta curiosité en ce moment.

Pour chaque domaine, note :

- pourquoi il t'attire ;
- depuis quand il revient ;
- une personne à observer ;
- une action simple pour tirer le fil.

Sortie attendue :
Choisir une curiosité et poser une action concrète : lire, appeler, visiter, tester, écrire, observer.

## 3. Découper l'éléphant

À utiliser quand le projet paraît trop grand.

Consigne :
Écris ton grand projet, puis découpe-le en actions si petites qu'elles deviennent réalisables.

Questions :

- Quelle serait la version de 20 minutes ?
- Quelle serait la version sans risque ?
- Quelle serait la version brouillon ?
- Quelle serait la première conversation ?
- Quelle action peut être faite aujourd'hui ?

## 4. Si c'était simple, comment ce serait ?

Consigne :
Au centre d'une page, écris : "Si c'était simple, qu'est-ce que je ferais ?"

Autour, note toutes les réponses sans les censurer.

Puis choisis :

- l'action la plus facile ;
- l'action la plus joyeuse ;
- l'action la plus utile ;
- l'action la plus rapide.

Fais-en une.

## 5. La jalousie comme boussole

Consigne :
Liste trois personnes que tu envies ou dont le parcours te pique.

Pour chacune, distingue :

- ce que tu crois lui envier ;
- ce que tu lui envies vraiment ;
- ce que cela révèle de ton désir ;
- ce que tu peux emprunter ;
- une action inspirée, mais personnelle.

## 6. La zone de brillance

Consigne :
Liste toutes les qualités que l'on t'a reconnues depuis l'enfance.

Sources possibles :

- famille ;
- amis ;
- collègues ;
- clients ;
- professeurs ;
- personnes rencontrées récemment.

Ensuite, entoure trois à cinq qualités que tu ne veux pas abandonner.

Formule :
"Ma zone de brillance actuelle semble être : ..."

## 7. Comment pourrais-je gagner de l'argent ?

Consigne :
Organise une séance sans censure. Toute idée est bienvenue.

Catégories :

- revenus actuels à consolider ;
- offres simples ;
- métiers connexes ;
- prestations ponctuelles ;
- produits ;
- ateliers ;
- accompagnements ;
- partenariats ;
- contenus ;
- travail alimentaire compatible.

Puis classe les idées :

- facile à tester ;
- rentable ;
- alignée ;
- sécurisante ;
- à explorer plus tard.

## 8. Donner ou vendre

Consigne :
Crée deux colonnes : "Je donne" et "Je vends".

À clarifier :

- ce qui nourrit la relation ;
- ce qui sert la visibilité ;
- ce qui relève du plaisir ;
- ce qui demande trop de temps pour être gratuit ;
- ce qui a une valeur professionnelle ;
- ce qui doit être facturé.

Objectif :
Aider l'utilisateur à donner joyeusement et à vendre sans culpabilité.

## 9. Les petites victoires

Consigne :
Liste cinq petites victoires récentes.

Pour chacune :

- ce que tu as fait ;
- pourquoi c'est une victoire ;
- ce que cela dit de toi ;
- comment tu peux la célébrer ;
- quel pas suivant elle rend possible.
