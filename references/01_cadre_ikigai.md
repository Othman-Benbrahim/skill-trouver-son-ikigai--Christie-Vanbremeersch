# 01 — Cadre Ikigaï

## Définition opérationnelle

Dans ce skill, l'Ikigaï est défini comme une zone d'équilibre entre quatre pôles :

1. **Ce que l'utilisateur aime** : ce qui l'anime, l'absorbe, le rend curieux, vivant ou joyeux.
2. **Ce dans quoi il est bon** : qualités, compétences, dons, expériences, zone de brillance.
3. **Ce dont le monde a besoin** : contribution, service, public, problème réel à résoudre.
4. **Ce qui peut le faire vivre** : rémunération, modèle économique, métier connexe, sécurité matérielle.

L'Ikigaï n'est pas forcément un métier unique. Il peut être :

- une activité professionnelle ;
- une combinaison de métiers ;
- un projet entrepreneurial ;
- une vocation artistique ou de service ;
- un équilibre entre travail rémunéré et contribution gratuite ;
- une dynamique de vie.

## Les quatre profils d'utilisateurs

### 1. Ikifauché

La personne a une passion, une vocation ou un projet, mais ne parvient pas encore à en vivre.

Accompagnement recommandé :

- clarifier ce qui peut être vendu ;
- distinguer gratuit, don, visibilité et offre rémunérée ;
- chercher des revenus complémentaires ;
- tester une première proposition simple.

### 2. Ikennuyé

La personne gagne sa vie, mais son travail manque de sens, de joie ou d'énergie.

Accompagnement recommandé :

- repérer ce qui l'épuise ;
- identifier les moments où elle se sent compétente et vivante ;
- explorer des ajustements internes avant la rupture ;
- imaginer des tests hors travail.

### 3. Ikistagnant

La personne est dispersée, confuse, bloquée ou paralysée par la peur.

Accompagnement recommandé :

- recentrage ;
- carnet ;
- liste de curiosités ;
- action minuscule ;
- célébration des petites victoires.

### 4. Ikigâté

La personne a déjà trouvé un équilibre satisfaisant, mais doit l'entretenir.

Accompagnement recommandé :

- réévaluer régulièrement ses besoins ;
- protéger ses rituels ;
- ajuster ce qui est donné ou vendu ;
- célébrer ;
- éviter l'épuisement.

## Idée clé

L'Ikigaï n'est pas un acquis définitif. C'est un équilibre vivant qui se cultive, se perd parfois, se retrouve, se réajuste selon les âges, les contraintes, les besoins et les opportunités.
